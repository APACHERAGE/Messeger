# История версий Nightfall

Этот файл отделяет подтверждённые изменения от предположений. Версия приложения хранится в `package.json`, `package-lock.json` и `backend/pom.xml`; все три манифеста согласованы на `1.0.0`.

## 0.7.x и 0.8.x — история не установлена

В доступном Git-репозитории нет тегов или коммитов релизов `0.7.x` и `0.8.x`. Самый ранний коммит `b7cfa3d` — снимок уже существующего приложения перед укреплением версии 1.0. Поэтому точно распределить функции между 0.7 и 0.8 нельзя: это было бы выдуманной историей. Если найдутся архивы, установщики или старые Git-репозитории этих версий, разделы можно восстановить по их исходникам.

## 0.1.0 — прежняя техническая версия

До обновления манифестов 11 ноября 2026 года клиент и сервер указывали `0.1.0`, хотя [CHANGELOG.md](./CHANGELOG.md) уже называл готовящийся набор изменений `1.0.0`. Это был номер сборки в исходниках, а не доказательство отдельного опубликованного релиза. Базовый снимок сохранён в Git-коммите `b7cfa3d`.

## 1.0.0 — текущая версия исходников

Подтверждённый диапазон изменений: `b7cfa3d` → `78de6a6` и последующие локальные исправления. Подробный список — в [CHANGELOG.md](./CHANGELOG.md).

| Изменение | Зачем оно понадобилось |
| --- | --- |
| Проверка регистрации привязана к конкретной заявке и паролю; есть лимиты запросов | Исключить подтверждение чужой предварительной регистрации и затруднить спам/подбор |
| Поддержка SMTP-отправки приглашения, приветствия и сброса пароля | Направлять ссылки на указанный внешний адрес, а не только в журнал разработчика |
| Маскировка паролей, токенов и кодов приглашения в строковом представлении запросов | Даже при случайно включённом подробном журнале не раскрывать эти значения |
| Упрощённая форма регистрации и отдельное приглашение по email | Уменьшить число полей и явно разделить внутренний ящик `@nf.com` и внешнюю почту |
| Мобильная навигация, безопасные отступы экрана, PWA-манифест | Сделать основные разделы доступными на узких экранах и через «Добавить на главный экран» |
| Ограниченные выборки, проверка вложений и профиля, заголовки безопасности | Снизить расход памяти, отклонять поддельные файлы и уменьшить риск браузерных атак |
| Исправление задачи публичного запуска | Запускать собранное приложение с API и настройками почты, а не публиковать Vite-сервер разработки |
| Запрет захвата незавершённой регистрации при выключенной проверке почты | Не позволять новому запросу менять пароль и активировать ранее созданный неподтверждённый аккаунт |
| Необязательный код приглашения по умолчанию | Новому пользователю достаточно обычной регистрации; старый аккаунт доступен через вход |

Номер `1.0.0` означает согласованную версию исходников. Публичную доступность и доставку Gmail можно считать проверенными только после запуска туннеля и пробной отправки с локально введённым паролем приложения Google. Эти проверки не следует подменять результатами модульных тестов.
